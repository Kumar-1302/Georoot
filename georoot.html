How GeoRoot knows.

Each metric is tagged so you can tell measured weather from model output, user input and demo data.

MetricTypeSource
📡 Sensor data

No physical sensors are connected. Soil moisture is Open-Meteo's modelled top-soil value.

🌦 Weather data

Open-Meteo forecast and archive APIs (free, no key). If a call fails, GeoRoot falls back to a latitude-based model and says so.

🗺 Map data

Leaflet with OpenStreetMap tiles. Land type and green cover are demo values, not satellite land cover.

🌱 Ecological data

Species traits are hand-curated approximations for a prototype.

🤖 AI analysis

Scores and text come from transparent rules on this page. The assistant does not call a language model.
